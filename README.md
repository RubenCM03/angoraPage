# Angora Page - Réplica de Interfaz Web

## 📋 Descripción

Este proyecto es una réplica de una página web desarrollada como parte de la asignatura **Diseño de Interfaces Web**. El objetivo principal fue codificar fielmente una captura de pantalla de un sitio web existente, poniendo en práctica los conocimientos adquiridos sobre el framework **Bootstrap** y las mejores prácticas de desarrollo front-end.

## 🎯 Objetivos del Proyecto

- Aplicar los conceptos de diseño responsive utilizando el sistema de grid de Bootstrap
- Implementar componentes de Bootstrap (navegación, cards, botones, etc.)
- Replicar con precisión el diseño y la estructura visual de una interfaz web
- Desarrollar habilidades de maquetación y atención al detalle
- Crear código HTML semántico y CSS organizado

## 🛠️ Tecnologías Utilizadas

- **HTML5** (91%) - Estructura semántica del contenido
- **CSS3** (9%) - Estilos personalizados y ajustes visuales
- **Bootstrap** - Framework CSS para diseño responsive y componentes

## 📂 Estructura del Proyecto

```
angoraPage/
├── index.html          # Página principal
├── css/               # Archivos de estilos personalizados
└── assets/            # Imágenes y recursos multimedia
```

## 🚀 Cómo Visualizar el Proyecto

1. Clona este repositorio:
   ```bash
   git clone https://github.com/RubenCM03/angoraPage.git
   ```

2. Navega al directorio del proyecto:
   ```bash
   cd angoraPage
   ```

3. Abre el archivo `index.html` en tu navegador preferido
